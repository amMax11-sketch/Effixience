# Effixience

A calm space for tasks, habits, and deep work.

**Live demo:** (https://ammax11-sketch.github.io/Effixience/)

### Features
- Tasks with priorities and filters
- Daily habits
- Focus timer
- Dopamine Donor (earned breaks)
- Weekly intention
- Local-only (no account needed)

### How to use
Open `index.html` in any modern browser, or visit the live demo.
